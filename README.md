# Novsky Starter

A fresh Telegram assistant whose owner defines its purpose. The required base
includes durable memory, Novsky Vault, semantic/vector search and voice-message
transcription. The browser supports ordinary web tasks;
there is no specialist persona or preset list of business connections.

Creating Starter in Novsky requires an OpenAI API key for voice transcription
and semantic memory. The app enables this foundation explicitly. Installation
checks the initial vector index, while the first voice message verifies the live
transcription service. An API key being present alone does not prove either
service is working.

Start with `ONBOARDING.md`. Add the skills and connections needed for real tasks
later. An optional private backup protects the owner's notes. Existing memory
and deliberate feature settings survive updates.

Novsky Vault retains the existing `obsidian-vault` directory for compatibility
and works without another notes application.
