# Встановлення Novsky Starter

Цей приватний репозиторій встановлює одного спеціалізованого Telegram-агента:
`Novsky Starter`.

Novsky Starter безкоштовний: ключ покупки не потрібен, інсталятор
не звертається до сервісу активації.

1. Підготуй підписку Claude Pro або Max: цей архів установлює агента, який
   працює на Claude Code. Далі потрібні VPS з Ubuntu 24.04 і root-доступом,
   токен Telegram-бота, числовий Telegram ID власника, часовий пояс та ім’я
   агента.
2. Відкрий розпаковану папку у своєму кодинг-агенті — Claude Code, Codex,
   Cursor чи іншому — і напиши «установи мені асистента». Якщо агент працює
   в пісочниці (Codex за замовчуванням), дозволь йому мережу та SSH:
   серверні етапи `DEPLOY.md` він виконує через з’єднання з твоїм VPS.
3. Клонуй цей репозиторій до `/opt/claude-tg-starter` через
   `scripts/clone-product.sh`.
4. Запусти `bash onboard.sh` від root і пройди короткі браузерні кроки
   авторизації, які він покаже.
5. Заверши налаштування для цього продукту за `ONBOARDING.md`.
6. Виконай `VERIFY.md`, перш ніж передавати агента власникові.

Інсталятор просить лише інтеграції, оголошені цим продуктом. Необов’язкові
Розпізнавання голосових і резервну копію пам’яті можна підключити пізніше.
