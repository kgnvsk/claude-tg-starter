# Codex: установка на твой сервер

Распакуй ZIP Codex Premium или другого комплекта Codex и открой всю папку в
Codex или Claude Code. Приложение Novsky и аккаунт Novsky не нужны. Бот будет
работать на твоём Ubuntu-сервере под отдельным Linux-пользователем.

Напиши агенту:

> Установи этот комплект на мой Ubuntu-сервер. Прочитай `codex/standalone/AGENTS.md`,
> проверь архив и сервер, установи бота и помоги мне войти в Codex. Доведи установку
> до настоящего ответа в Telegram и проверки голосового сообщения и файла.
> Запроси только недостающие данные; секреты передавай через приватный файл.

## Что приготовить

- Сервер с Ubuntu 22.04 или 24.04, systemd и доступом в интернет; SSH-доступ
  с правами root либо разрешённым переходом к root для установки.
- Токен твоего бота из BotFather и твой числовой Telegram user ID для личного
  чата. `@username`, ID канала и ID группы не подходят.
- Твой вход в Codex и браузер, в котором ты завершишь авторизацию OpenAI.
- Твой OpenAI API key с доступным API-балансом для распознавания голоса и
  векторной памяти. Этот ключ и вход в Codex выполняют разные задачи.

Имена агента и владельца и часовой пояс можно указать сразу. Без них используются
нейтральные `Codex`, `Owner` и `UTC`. Часовой пояс задаётся в формате IANA,
например `Europe/Lisbon`. Поле `model` необязательно: добавь его только если
хочешь выбрать конкретную доступную тебе модель.

## Что сделает агент установки

Он проверит состав и хеши комплекта, состояние сервера и возможные конфликты,
перенесёт комплект в отдельную папку и запустит встроенный установщик.
Установщик создаёт отдельного пользователя `codex-<ID твоего бота>`, готовит
Node, Bun, Codex, рабочую папку, память, навыки, плагины и предусмотренные
комплектом браузерные и корпоративные процессы. Для этого не нужно отдельно
ставить глобальные копии Node, Bun или Codex.

Установочные права root не передаются Telegram-агенту. Рабочая папка и память
находятся в `/home/<user>/obsidian-vault/`, а основной сервис называется
`codex-telegram@<user>.service`. Точное имя пользователя возьми из результата
установки. Внутренние имена Novsky в путях не требуют приложения Novsky.

## Команды для проверки и установки

Если агент выполняет установку за тебя, этот раздел служит ему инструкцией.
На Mac или Linux из корня распакованного ZIP:

```sh
python3 codex/server.py verify
```

После проверки перенеси всю папку на сервер, сохранив вложенный каталог
`codex/`, и проверь её той же командой. Следующие команды выполняются на
Ubuntu-сервере от root, из корня перенесённого ZIP.

Создай приватный файл вне комплекта:

```sh
CODEX_INSTALL_CONFIG=$(mktemp /root/codex-install.XXXXXX.json)
cp codex/standalone/config.example.json "$CODEX_INSTALL_CONFIG"
chmod 600 "$CODEX_INSTALL_CONFIG"
```

Заполни этот файл через приватный редактор или защищённую передачу файла.
Все значения `REPLACE_WITH_…` в примере — заглушки, с ними установка не
работает. Не вставляй токены в команду, не выводи файл в терминал и не сохраняй
его в Git. Установка читает JSON через stdin:

```sh
python3 codex/server.py install < "$CODEX_INSTALL_CONFIG"
```

При успешной установке сохрани результат с пользователем, сервисом, версией
и путём резервной копии. Затем удали временный файл с секретами:

```sh
unlink "$CODEX_INSTALL_CONFIG"
```

В следующих командах замени пример `codex-1234567890` точным пользователем из
результата установки:

```sh
AGENT_USER=codex-1234567890
python3 codex/server.py login --user "$AGENT_USER"
```

Команда запускает официальный `codex login --device-auth` от имени нового
пользователя. Открой показанную ссылку в своём браузере и введи одноразовый код
из своего приватного терминала. Если вход по коду отключён, включи его в
настройках безопасности ChatGPT либо обратись к администратору своей рабочей
области. Не публикуй код или файл `auth.json`.
[Официальная инструкция OpenAI](https://learn.chatgpt.com/docs/auth).

После успешного входа:

```sh
python3 codex/server.py start --user "$AGENT_USER"
python3 codex/server.py status --user "$AGENT_USER"
python3 codex/server.py verify-reply --user "$AGENT_USER"
```

Последняя команда ожидает новый настоящий ответ. Пока она ждёт, открой
личный чат со своим ботом и отправь уникальную фразу, например «Ответь:
проверка 7e3». Убедись, что пришёл соответствующий ответ. Затем проверь:

1. Голосовое: произнеси короткую фразу и попроси повторить смысл текстом.
2. Файл: отправь небольшой несекретный документ и попроси обработать его
   и вернуть результат отдельным файлом. Открой полученный файл.

Статус `active` и успешный запуск не заменяют эти проверки. Если вход или
проверка ещё ожидают твоего участия, установка должна быть отмечена как
незавершённая, с конкретным оставшимся шагом.

## Интеграции, повторная попытка и восстановление

Google и другие внешние сервисы подключаются твоими собственными аккаунтами
и ключами. Платные поставщики оплачиваются отдельно. До подключения и проверки
такие возможности имеют статус `unconfigured`; наличие навыка или плагина
само по себе не означает, что аккаунт подключён.

При существующей установке сначала нужна серверная резервная копия затрагиваемых
файлов, памяти, конфигурации и авторизации. При ошибке сохрани эту копию и папку
установки, исправь указанную причину и повтори установку того же проверенного
комплекта. Не удаляй пользователя, память или изменённые файлы ради повторной
попытки. При восстановлении не затирай новые данные старой копией.

Установка не должна менять SSH, firewall и соседние сервисы. Если такой же бот
уже запущен, сначала нужно установить, кому принадлежит текущая установка;
второй получатель сообщений с тем же токеном запускать нельзя.
