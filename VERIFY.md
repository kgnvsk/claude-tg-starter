Не передавай агента клієнтові, доки не завершено кожну обов’язкову перевірку.

## Ідентичність продукту

- [ ] `PRODUCT.json` повідомляє `starter`
- [ ] Якщо цю копію клоновано з приватного репозиторію, команда
      `git remote get-url origin` визначає `https://github.com/kgnvsk/claude-tg-starter.git`. Дистрибутив,
      розпакований з архіву, не має git metadata й пропускає цю перевірку.
- [ ] `~/bin/skill-doctor` повідомляє лише навички, що входять до цього
      продукту
