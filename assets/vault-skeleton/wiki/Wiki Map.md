# Wiki Map — структура пам’яті

- `../Теми/` — теми власника: по папці на тему з людською назвою («Здоров'я», «Проєкти/Сайт»), усередині оглядова нотатка й записи; це те, що бачить і править власник (Novsky → Мозок). Усе, що записується для власника, іде сюди
- `hot.md` — гарячий кеш, інжектується в кожну сесію (тримати коротким)
- `log.md` — журнал подій (нове зверху)
- `entities/` — картки людей/компаній/проєктів (1 файл = 1 сутність, `[[посилання]]`)
- `concepts/` — знання і рішення для повторного використання
- `sources/` — зовнішні посилання/матеріали
- `tasks/` — завдання і нагадування
- `projects/` — робоча картина кожного проєкту/чату: рішення, домовленості (хто/що/дедлайн/статус), відкриті питання. 1 файл = 1 проєкт
- `meetings/` — нотатки зустрічей, файл `РРРР-ММ-ДД-<тема>.md`
- `../_templates/` — шаблони нотаток; `../_attachments/` — файли/зображення

Правило (з CLAUDE.md): у vault — лише те, що можна використати повторно; одноразове — у /tmp.
