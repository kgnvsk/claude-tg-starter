# Команда / Team

Реєстр для PM-режиму: власник диктує боту, хто є хто — бот сам доповнює таблицю («запам’ятай: 123456 — це Петро, дизайнер на проєкті X»).

| tg_id | Ім’я | Роль | Проєкти/чати | Нотатки |
|---|---|---|---|---|
| | | | | |

## Правила
- tg_id — з пересланого повідомлення або власник дізнається його в співробітника (@userinfobot).
- Для особистих пінгів співробітник має один раз написати боту /start (Telegram не дозволяє ботам писати першими).
- Спостережувані чати зберігаються в `access.json → groups`: коли власник додає бота, читання вмикається автоматично. Власник керує ним звичайним текстом або голосом; агент застосовує зміну через `group-observation`.
