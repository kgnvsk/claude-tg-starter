# Про теми

Тут живе те, що агент записує для тебе, розкладене по темах: одна папка — одна тема з людською назвою («Здоров'я», «Мої фінанси», «Проєкти»). Усередині — звичайні нотатки; в кожній темі є оглядова нотатка з назвою теми: що це, що відстежуємо, останній стан.

- Нову тему створює агент («створи тему Здоров'я і веди мене по ній») або ти сам у Novsky (Мозок → «+ Тема»).
- Теми можуть вкладатися: `Проєкти/Сайт`.
- Усе можна правити руками: це прості текстові файли (Markdown), їх видно й у Novsky, і в будь-якому редакторі нотаток.

Папки `wiki/` і `learning/` поруч — службові записи самого агента; для людини головне тут.
