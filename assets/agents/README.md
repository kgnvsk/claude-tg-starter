# Субагенти цього бота

Тут живуть **субагенти** — спеціалізовані підвиконавці, яких бот викликає
для окремих завдань (дослідження, рев'ю коду, будь-що). Це нативна можливість Claude Code:
**один `.md`-файл = один агент.** Їхні токени йдуть на ту саму підписку, що й у бота —
окремий тарифікований пул не використовується.

## Як додати свого агента

1. Створи файл `ім'я-агента.md` у цій папці (`~/.claude/agents/`).
2. Заповни його за форматом нижче.
3. **Перезапусти бота**, щоб він побачив нового агента:
   `sudo systemctl restart claude-telegram`
   Поки не перезапустиш — новий файл НЕ підхопиться.

## Формат файла

    ---
    name: ім'я-агента          # обов'язково: малі літери й дефіси
    description: Коли мене кликати — 1-2 речення. Бот читає це й сам вирішує делегувати.   # обов'язково
    tools: WebSearch, WebFetch, Read, Grep, Glob   # необов'язково: через кому (НЕ список). Порожньо = усі інструменти.
    model: opus               # завжди opus: субагент відповідає за якість так само, як ти
    ---

    Тут — системний промпт агента: хто він, як працює, що повертає.

Обов'язкові лише `name` і `description`. Решта — необов'язково.

## Як бот їх викликає

- **Сам**, коли твоє завдання збігається з `description` агента.
- **За ім'ям**, якщо попросиш прямо: «візьми researcher і збери інформацію про …».

## Важливо про ліміт

Кожен субагент — повноцінна підсесія. Працює на підписці (не на окремому
платному пулі), але **витрачає лімітне вікно швидше** за звичайний чат. Для легких завдань
залишай агенту `model: opus` — субагент потрібен заради зв'язку, а не заради економії.
