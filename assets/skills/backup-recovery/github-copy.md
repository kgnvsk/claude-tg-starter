# Додаткова приватна копія пам’яті в GitHub

Розділ правил кита. На кожному ході в правилах лишився лише вказівник сюди; читай цей файл повністю, коли до цього доходить.

Лише якщо адміністратор окремо просить попередню читабельну копію пам’яті, проведи його по одному
кроку. Він створює порожній приватний GitHub-репозиторій. Запусти
`~/bin/agent-github-backup setup-key`, покажи лише публічний ключ і попроси
додати його в GitHub як Deploy key з дозволом на запис. Потім, лише після
підтвердження приватності, виконай
`~/bin/agent-github-backup connect --remote git@github.com:OWNER/REPO.git --confirm-private`.
Команда негайно створить і перевірить першу резервну копію. Перевір стан через
`~/bin/agent-github-backup status --json`.

Ніколи не читай і не надсилай приватний deploy key. `.env`, токени, сирі чати,
сесії, Telegram DB, логи, кеші й індекси не входять до копії. Під час аварійного
відновлення спочатку потрібна та сама версія комплекту; секрети й доступи
відновлюються окремо.
