# video-craft — как снять видео на нашем уровне

## Правило №0 — стиль НЕ дефолтный, СПРОСИ
Когда просят «сделай видео» без явного стиля — НЕ начинай молча (и НЕ делай тёмный-люкс по умолчанию: он один из вариантов, не дефолт). Сначала короткий бриф одним вопросом с вариантами (дай рекомендацию, но выбирает пользователь):
- **Вайб/палитра:** dark-luxe · light-editorial · bold-contemporary · свой.
- **Движение:** спокойный премиум (раскрытия по маске, каунт-ап) · хлёсткий кинетик в ритм (без «игрушечного» баунса).
- **Аудио:** мелодия-интро · только бит · закадр (TTS) · без звука.
- **Формат/длина:** 16:9 1920×1080 · 9:16 вертикаль · сколько секунд.
Если пользователь стиль назвал — не переспрашивай, делай.

## 1. Шрифты → skill `brand-fonts`
Характерный + кириллица. Премиум: **Fixel** (MacPaw), Unbounded. Для рендера **вшивай woff2 как base64** (`embed-fonts.py` рядом), иначе шрифт отвалится на части кадров.

## 2. Палитра-пресеты (ВАРИАНТЫ, не дефолт)
- **dark-luxe:** bg `#0c0d10` · ink `#ece7db` · accent `#e0a43c` янтарь · зерно+виньетка. На тёмном шрифт играет сильнее.
- **light-editorial:** bg `#eceae1` · ink `#181510` · accent `#bf4326` клэй · хайрлайны + моно-метаданные, швейцарская сетка.
- **bold-contemporary:** bg `#f3efe6` · ink `#1a1611` · accent `#e5402a` · Unbounded, чипы.
Единый **HUD** (хайрлайны + kicker + индекс сцены + живой таймкод) через все сцены = премиум-когезия. Крупные слова раскрывай **по маске** (`overflow:hidden` обёртка + `yPercent 115→0`), а не баунсом.

## 3. Аудио как МЕЛОДИЯ (если выбрали мелодию) — не луп битов
Короткая партитура С НАЧАЛОМ И КОНЦОМ (шаблон `audio-intro.py` рядом, синтез numpy, без внешних сервисов):
- Тональность + прогрессия С РАЗРЕШЕНИЕМ (напр. Ля-минор: Am→F→C→G→…→Am).
- Слои: бас (корни на долю) + арпеджио (8-е, chord tones) + лид-хук (в кульминации) + перкуссия.
- Драматургия: тихое интро → нарастание → пик-хук → финальный аккорд с **ХВОСТОМ** (в последнем такте убери перкуссию, дай аккорду отзвенеть) → фейд-аут.
- **Сетка:** положи сцены на такты (BPM), тогда удары «завершаются». Пример: 128 BPM → такт 1.875с → 8 тактов = 15.0с. Удары/whoosh — на сменах сцен.
- Мукс: `ffmpeg -i video.mp4 -i beat.wav -c:v copy -c:a aac -b:a 192k out.mp4` (без `-shortest`, если длины равны).

## 4. ⚠️ ОБЯЗАТЕЛЬНО: покадровая проверка ДО отдачи
`hyperframes inspect` сэмплит ~9 точек и ПРОПУСКАЕТ обрезку между ними — на него НЕ полагайся. Гейт перед отдачей:
1. Отрендерь черновик (`-q draft` быстрее).
2. Вытащи по кадру из СЕРЕДИНЫ каждой сцены: `ffmpeg -ss <t> -i video.mp4 -frames:v 1 s<N>.png`.
3. Посмотри КАЖДЫЙ кадр глазами (Read png). Проверь на каждом:
   - текст не обрезан краем кадра (влезает в 1920×1080 с полями ~140px);
   - слова/числа не налазят друг на друга (есть зазор между hero и колонкой);
   - шрифт подхватился (не системный фолбэк — характерные формы на месте);
   - каунт-апы показывают верное значение.
4. Нашёл проблему → уменьши кегль / сдвинь / дай зазор, перерендерь, ПЕРЕПРОВЕРЬ все сцены заново.
5. Только когда ВСЕ сцены чистые — своди аудио и отдавай.

**Частый баг:** хрупкие `nth-child` селекторы промахиваются при вложенности (слово в обёртке) → остаётся спрятанным под маской. Селекти по классу или `#scene .m > span` со стаггером, НЕ по `nth-child`.

## Отдача
Отдавай сам результат (mp4), не имя файла. Через бота: `curl -F chat_id=<id> -F video=@out.mp4 -F "caption=</tmp/cap.txt" .../sendVideo` (подпись из файла, чтобы кириллица/переносы не поломали shell).

## Сборка
Собирай видео скиллами `hyperframes` / `motion-graphics` (соблюдай их seek-safe контракт: единый `gsap.timeline({paused:true})` на `window.__timelines["main"]`, `tl.seek(0)`, раскрытия через `autoAlpha`/transform, каунт-ап через onUpdate-прокси, детерминизм). video-craft — это бриф + пресеты + аудио + гейт качества поверх них.
