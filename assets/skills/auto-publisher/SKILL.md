# auto-publisher — развернуть авто-паблишер (вшитый пакет StreamPost)

Код лежит рядом: **`pkg/`** (`~/.claude/skills/auto-publisher/pkg/`) — лёгкий python-сервис (telethon + httpx). Конфиги (`sources.json`/`filters.json`/`style.md`/`admin.json`) — hot-reload, без рестарта. Ничего скачивать/клонировать не нужно.

## Архитектура (объясни пользователю)
- Отдельный сервис (systemd `streampost`), но **публикует ТЕМ ЖЕ ботом, что и сам агент** — переиспользует токен агента. **Отдельного бота НЕ создаём.** Он только **шлёт** в канал (`sendMessage`, апдейты не поллит) → с чат-ботом агента не конфликтует.
- Нужно одно действие: **добавить бота агента админом (Post Messages)** в целевой канал. Токен уже в `.env` агента.
- **Источники читает юзер-сессия** (личный Telegram-аккаунт, API ID/Hash с my.telegram.org) — ботом чужие каналы читать нельзя.
- **Рерайт** через Claude Max прокси (дефолт, нужен gateway на боксе) или Anthropic API-key (проще на новом боксе).

## Онбординг — В ЧАТЕ, пошагово (не гони install.sh молча)
1. **Ниша.** Про что канал? Язык? Тон (живой/ироничный vs сдержанный экспертный)?
2. **Источники.** TG-каналы (@username) + RSS/сайты (помоги найти `/feed`/`/rss` у сайта).
3. **Целевой канал** (бот = сам агент, нового НЕ создаём): создай/возьми канал, **добавь бота агента админом** (Post Messages); channel ID через **@userinfobot** (репостни пост канала → покажет `-100…`).
4. **Ключи.** API ID + API Hash (**my.telegram.org**) — для юзер-сессии. Свой **user_id** (@userinfobot). LLM: api-key (проще) или claude-max gateway. Токен бота НЕ спрашивай — берётся токен агента.
5. **Стиль (генерик — спроси и напиши сам).** По нише/языку/тону составь `configs/style.md`. Покажи 1-2 примера постов ДО запуска. Опорный эталон уже лежит в `pkg/configs/style.md` (украинский AI-ньюс: режимы LIGHT/THINK, HTML-only, лид=суть-фичи-не-метрика, только короткий дефис) — адаптируй под нишу, НЕ копируй язык вслепую.

## Деплой (после согласования)
Проверь, что автопаблишер тут ещё НЕ крутится (не задвоить): `systemctl is-active streampost 2>/dev/null`. Если активен — правь конфиги существующего, не ставь второй.
```bash
# токен агента (подставь на вопрос про bot token, НЕ создавай нового бота):
grep '^TELEGRAM_BOT_TOKEN=' ~/.claude/channels/telegram/.env
cd ~/.claude/skills/auto-publisher/pkg && bash install.sh   # копирует пакет в /opt/streampost, ставит зависимости, спросит API ID/Hash, bot token, channel ID, user_id, LLM, поставит systemd
```
После установки **впиши источники** в `/opt/streampost/configs/sources.json` и **стиль** в `/opt/streampost/configs/style.md` (hot-reload). Ключи остаются в `/opt/streampost/.env` на боксе, никуда не уходят.

⚠️ **Человеческий шаг:** `create_session.py` (внутри install.sh) логинит юзер-сессию — Telegram пришлёт **код в приложение**, вводит ПОЛЬЗОВАТЕЛЬ. Без этого источники не читаются. Единственное место, где нужен человек в реальном времени.

## Проверка (до «готово»)
1. `systemctl is-active streampost` → active.
2. `journalctl -u streampost -n 40` → видит источники, нет ошибок авторизации.
3. Дождись/спровоцируй первый пост → проверь, что он реально В КАНАЛЕ (бот-админ работает) и в нужном стиле. Покажи его пользователю, правь `style.md` (hot-reload).

## Частые грабли
- Публикация молчит → бот НЕ админ канала (или нет Post Messages).
- Источники пустые → юзер-сессия не залогинена (`create_session.py`) или каналы приватные/не те @username.
- LLM не отвечает → выбран claude-max, но gateway на боксе не поднят → переключи на Anthropic API-key в `/opt/streampost/.env`.
- Рекламный шум → правь `configs/filters.json`. Длинное тире/markdown в постах → ужесточи `style.md` (HTML-only, только `-`).
