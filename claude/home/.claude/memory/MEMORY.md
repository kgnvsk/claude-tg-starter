# Memory map

Keep this file under 2,200 characters.

One line per thing: what it is - where it lives. List what you would otherwise have to find again: notes and
folders of the vault, working files and documents (with their links), your own programs, saved accesses (where
they are kept, never the secret itself), standing lists. Details stay in those files and come back with
memory-search. The few standing facts about your environment that every session needs live here too.
